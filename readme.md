# TODO 小组件

一个轻量、无边框的桌面待办小组件，常驻桌面角落，不占任务栏，随时记录你的任务与图片。

## 功能特性

- **多列表管理**：监考、我的课表、晚自习、3班课表、6班课表……按需自由增删列表，标签拖拽排序
- **文字任务**：随时添加，点击圆点一键反选完成状态，拖拽调整顺序
- **图片任务**：支持拖入/粘贴/选择文件添加图片，点击缩略图展开原图，也可在系统图片查看器中打开
- **数据安全**：数据自动保存在本地文件，重启不丢失；支持导出/导入备份
- **无边框窗口**：无标题栏、不占任务栏，像一个小便签一样安静
- **系统托盘**：双击托盘图标显示/隐藏，右键退出

## 安装与启动

### 方式一：一键安装（推荐）

双击 `安装桌面小组件.bat`，自动完成：

1. 创建桌面快捷方式「TODO小组件」
2. 添加开机启动项（开机自动运行）

之后双击桌面「TODO小组件」即可使用。

### 方式二：命令行

```bat
:: 安装快捷方式 + 开机启动（运行一次即可）
python serve.py --install

:: 手动启动
pythonw serve.py

:: 调试模式（前台运行，打印日志）
python serve.py --debug
```

## 使用说明

| 操作 | 方法 |
|---|---|
| 添加文字任务 | 顶部输入框输入后回车 |
| 添加图片任务 | 把图片拖入窗口 / 粘贴 / 点击图片按钮选择文件 |
| 完成 / 取消任务 | 点击任务左侧圆点 |
| 删除任务 | 鼠标悬停任务出现 ×，点击删除（图片任务 5 秒后确认清除） |
| 排序 | 拖拽任务卡片调整顺序 |
| 查看原图 | 点击图片任务缩略图展开灯箱；灯箱内可「在系统查看器中打开」 |
| 管理列表 | 底部「+」新建列表；拖拽列表标签排序 |
| 导出备份 | 顶部菜单 → 导出（含全部图片，JSON 文件） |
| 导入备份 | 顶部菜单 → 导入（自动清理不再引用的旧图） |
| 显示 / 隐藏 | 双击托盘图标 |
| 彻底退出 | 右键托盘图标 → 退出 |

## 数据与备份

| 文件 | 说明 |
|---|---|
| `widget-state.json` | 任务数据（列表/任务/状态） |
| `widget-images.json` | 图片原图数据 |
| `widget-backup.json.bak` | 手动保留的备份副本（**不要删除**，可作为最后的恢复手段） |
| `widget-data.json(.migrated)` | 早期版本的旧数据文件，首次启动新版后自动拆分迁移并归档（确认无误后可删除） |

> 首次升级到新版本后，程序会自动把旧数据迁移到新格式，原文件保留为 `widget-data.json.migrated`，核对无误后可手动删除。

## 常见问题

| 问题 | 解决 |
|---|---|
| 修改代码后界面没变化 | HTML 会自动热更新；若修改了 `serve.py`，请托盘退出后重新启动 |
| 窗口不见了 | 双击托盘图标即可重新显示 |
| 数据丢失 / 想恢复 | 使用导入备份功能，或查看 `widget-backup.json.bak` |
| 想彻底卸载 | 删除桌面快捷方式、移除开机启动项（`启动` 文件夹中的快捷方式），删除整个文件夹 |

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | 单文件 HTML + 原生 JS（localStorage / IndexedDB） |
| 宿主 | pywebview 6.2.1 + WebView2（无边框窗口） |
| 后端 | Python 标准库 HTTP 服务（127.0.0.1:8765）+ pystray 托盘 |
| 运行环境 | Windows，Python 3.13 + 系统 WebView2 运行时（Win10/11 自带） |
